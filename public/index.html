AskDocs — Grounded Document Q&A (RAG)

An AI micro-SaaS that answers questions only from your own uploaded documents and returns validated, cited JSON — never an ungrounded guess. Retrieval is hybrid: dense vector search fused with a BM25 keyword ranker (Reciprocal Rank Fusion), so exact-term matches surface even when semantic similarity misses them. Retrieved text is fed to the model as untrusted data behind a two-layer prompt-injection guard, and every answer ships with a live telemetry strip. Backed by a full engineering harness: eval suite, CI/CD, and per-user tenant isolation.

✓ Hybrid vector + keyword retrieval ✓ Cited, structured JSON answers ✓ Two-layer prompt-injection guard ✓ Per-user document isolation ✓ Live telemetry (tokens, latency, trace) ✓ Local embeddings — $0 per-query retrieval
